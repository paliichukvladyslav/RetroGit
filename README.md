# RetroGit

**RetroGit** — це локальний веб-сервіс для перегляду Git-репозиторіїв через браузер. Проєкт створено як легку та ресурсоефективну альтернативу перевантаженим інтерфейсам сучасних сервісів контролю версій.

## Можливості

- перегляд списку користувачів;
- рудиментарне створення нових профілів та локальних Git-репозиторіїв;
- перегляд README.md;
- перегляд історії коммітів;
- перегляд дерева файлів;
- відкриття вмісту окремих файлів;
- перемикання тем XP.css / 98.css / 7.css.

## Технології

- Rust
- Axum
- Askama
- Tokio
- HTMX
- Pulldown-cmark
- Git

## Запуск

Перед запуском потрібно встановити Rust і Git.

```bash
cargo run
````

Після запуску сервіс буде доступний у браузері за адресою:

```text
http://127.0.0.1:3000
```

## Структура даних

Усі користувачі та репозиторії зберігаються локально в директорії:

```text
repos/
```

Приклад структури:

```text
repos/
  username/
    avatar.png
    repository-name/
```

## Завантаження репозиторіїв із GitHub

Для швидкого наповнення локального сховища можна використати скрипт:

```bash
./fetch_repos.sh
```

Для роботи скрипта потрібна утиліта `jq`.

## Призначення

Проєкт розроблено в межах курсової роботи з дисципліни **«Основи веб-програмування»** на тему **«Сервіс системи контролю версій (Github, Bitbucket)»**.

## Звітні матеріали

Курсова робота, презентація та будь-які додаткові матеріали розміщені в директорії `reports/`.
